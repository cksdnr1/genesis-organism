# Synthetic encounter-v1 shapes

Distinct D07/D13 experimental schemas, not historical 0.1 replacements or standards.
Observer/policy are explicit typed claims; generated origin/state/event/evidence
are closed structural views of accepted contracts. UTF-8 byte budgets, signatures,
historical-source equality, semantic fidelity and idempotency need runtime checks;
JSON Schema character lengths alone do not enforce byte lengths. No remote resolver
or network schema fetch is required: validators use the local ID registry.
Core-v1 schemas and existing fixtures remain byte-identical historical evidence.
